# Add escalating waves

Give the endless POC session shape with escalating waves.

- A wave defines spawn pacing, simultaneous unicorn cap, and nervous ratio; each
  wave is a bit harder. Show `Wave N` in the HUD.
- Short calm gap between waves.
- No win/lose in the POC — waves escalate indefinitely and coins are the score.
- Leave a note in code for the candidate post-POC structures (money goal, rainbow
  power meter with celebration + best count, timed session) per the README.

## Acceptance criteria

- The HUD wave counter increments over time; later waves visibly bring more and
  more-nervous unicorns with shorter gaps.
- The game never ends; it stays playable (and stressful) indefinitely.
